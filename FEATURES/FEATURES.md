# Features Index

This directory contains design documents and progress trackers for major features and systems in the project.

Available feature docs:

- SpriteSheet to Animations Pipeline — `FEATURES/SpriteSheet-to-Animations.md`

How to add a feature document:

1. Create a new markdown file under this directory with a short title and status (e.g., `Character-Movement.md`).
2. Link the new file from `README.md` and add a short entry in `CHANGELOG.md` under `Unreleased` when you make changes.
