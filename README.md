# Avalon

## Overview
Avalon is an MMO prototype project created to validate game design ideas and practice Unity development and game server implementation.

## Purpose
This project serves as:
- A proof of concept for MMO mechanics and architecture
- A learning platform for Unity game development
- An opportunity to implement and test game server technologies

## Status
🚧 Prototype/Work in Progress
